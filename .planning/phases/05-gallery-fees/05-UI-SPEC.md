# Phase 5: UI Design Contract (Galeria i Cennik)

> Visual and interaction contract for the photo gallery, the fees page and the three
> new editorial-panel screens that feed them. Generated by gsd-ui-researcher, verified
> by gsd-ui-checker.
>
> **This document is UI-SPEC Amendment v1.7.** The Phase 1 contract and Amendments
> v1.1, v1.2, v1.3, v1.4, v1.5 and v1.6 stay in force in full. **Nothing here
> introduces a new colour value, a new font, a new font weight, a new type size or a
> new breakpoint.** Every value below already exists in `src/app.css` or in an approved
> amendment. This document composes those values onto the surfaces no previous phase
> defined, and it enumerates the authoritative Polish microcopy for every one of them.
>
> **This is a delta spec.** Where it is silent, Phase 1 (tokens, focus ring, motion,
> copy rules) governs the public surfaces, Amendment v1.4 governs form fields, and
> Amendment v1.5 (`04.1-UI-SPEC.md`) governs everything under `/admin`.

**Scope:** GALLERY-01, GALLERY-02, FEES-01. ROADMAP Phase 5 success criteria 1, 2 and 3.
**Explicitly out of scope:** CMS-01, CMS-02 and CMS-03. They are unticked and retargeted
to Phase 04.1 and only the 04.1 UAT closes them (05 D-36). This phase builds on a
formally open dependency by user decision (05 D-37) and says so rather than implying
the dependency is met.

**Stack context:** SvelteKit 2 + Svelte 5 runes + Tailwind v4 CSS-first `@theme` in
`src/app.css`. There is no `tailwind.config.js` and there never will be. shadcn/ui is
React-only and does not apply. Public content routes prerender at build time, so an
editor's save appears publicly after roughly two minutes.

**Language:** Polish only, every surface, no exceptions (SITE-06, CMS-03). Visitor copy
and panel copy alike: nav, labels, hints, validation, confirmations, empty states,
errors.

**Copy rules (v1.2 §8, non-negotiable, apply to shipped copy, code comments, test names
and commit messages):** no emoji, no em dashes anywhere (use commas, colons,
parentheses), en dash only inside numeric ranges (`6:30–16:30`), plain hyphen in day
abbreviations (`pon.-pt.`). Icons are bespoke SVG or Lucide, never emoji.

new value. Assignments this phase makes:

|-------|-------|------------------|
| `2xs` | 4px | Gap between a gallery caption and the tile below it in a stacked cell |
| `xs` | 8px | Caption to image gap; gap between a fee breakdown row's label and value when they wrap |
| `sm` | 12px | Control vertical padding (inherited exception, control padding only) |
| `md` | 16px | Panel padding (base), lightbox close-button inset, gap between a fee section's paragraphs |
| `lg` | 24px | **Gallery grid gap at every width** (05 D-12); panel padding (`md`+); `/cennik` block padding (`md`+); gap between `/cennik` sub-blocks |

**Hard rules added by this amendment:**
1. **The lightbox scrim is not a colour token, it is an overlay.** `rgb(15 23 42 / 0.72)`
   built from the existing `ink` triple, matching how `shadow-sm/md/lg` already express
   `rgba(15,23,42,...)`. It introduces no new hue. The close button sits on
   `brand-blue` with a white glyph (5.93:1), never on the scrim alone, because a control
   whose only backing is a translucent overlay has no guaranteed contrast against the
   photo behind it.
2. **A fee amount is never signalled by colour.** The payable amount is distinguished by
   size and weight, not by a red or green treatment. `danger` on a price would read as
   an error.
3. **Placeholder attributes remain banned on every control** (v1.4 hard rule 3). Guidance
   lives in a persistent hint wired via `aria-describedby`.
4. **No state is signalled by colour alone**, in either half of this phase.

## Component Contracts

### 1. Public gallery section on `/o-nas` (GALLERY-01, 05 D-19, D-20, D-12, D-24, D-25)

The gallery **replaces** section 6 („Nasze miejsce"). The seven-section order of
`02-UI-SPEC.md:109-115` is otherwise unchanged and no second photo set exists on the
page. `/galeria` is never built.

**Markup contract:**

```
<section id="galeria" tabindex="-1" aria-labelledby="galeria-heading" class="band">
  <div class="inner uklad-miejsce">
    <h2 id="galeria-heading">Galeria: nasze miejsce</h2>
    <p class="prose">{obiekt_opis, rendered with renderInline}</p>
    <ul class="galeria">  <!-- or the empty-state panel -->
      <li>
        <figure>
          <a href="{pełny obraz}" class="kafelek">
            <span class="visually-hidden">Powiększ zdjęcie: </span>
            <enhanced:img src={pic} alt="{alt}" sizes="..." />
          </a>
          <figcaption>{podpis}</figcaption>
        </figure>
      </li>
      ...
    </ul>
  </div>
</section>
```

- **Two attributes, two jobs, stated because they are easy to conflate.** `id="galeria"`
  is the fragment the footer link jumps to. `aria-labelledby="galeria-heading"` points at
  the `h2`'s own id. The old `obiekt-heading` id is retired with the old heading; renaming
  the section without renaming its heading id would leave a label that no longer describes
  the content.
- **`tabindex="-1"` on the section** so a keyboard user following the footer's „Galeria"
  link lands inside the gallery rather than at the top of the document.
- **`scroll-margin-top: 96px`** on the section so the sticky header never covers the
  heading. `scroll-behavior: smooth` is already inside the global reduced-motion
  neutraliser and is not re-declared here.
- **Heading text is „Galeria: nasze miejsce".** It answers the footer link labelled
  „Galeria" and keeps the „Nasze miejsce" framing that the page's warmth depends on. A
  bare „Galeria" loses the second; a bare „Nasze miejsce" makes the footer link land on a
  heading that does not match its own label.

**Grid (05 D-12 as amended):**

| Width | Columns | Gap | Notes |
|-------|---------|-----|-------|
| base | 1 | 24px | |
| ≥768px | 2 | 24px | inherited from the current facility grid |
| **≥1024px** | **3** | 24px | **NEW tier.** `02-UI-SPEC.md:115` stopped at two columns |

At ≥1024px the section is the v1.6 §2 editorial split (`minmax(220px, 300px) minmax(0, 1fr)`,
column-gap 48px) with the `h2` in the left rail. **The gallery `<ul>` spans both tracks**
(`grid-column: 1 / -1`), which is what `src/routes/o-nas/+page.svelte:210-217` already
does for `.gallery`, so the three-column tier and the editorial split do not fight. The
intro prose stays in the right track.

**Tile:**
- Aspect ratio **4:3**, reserved before the image paints (no CLS), `object-fit: cover`,
  `--radius-lg` on the image, 1px `--color-border-strong` is **not** applied: the photo is
  its own boundary and a border on a rounded photo reads as a frame the design system does
  not use elsewhere.
- Cropping is done at upload time by the panel island (Contract 8), centred, automatic, no
  cropper. The public page does no cropping beyond `object-fit: cover` as a safety net for
  the two hand-placed seed photos.
- **Loading:** every tile after the first two carries `loading="lazy"`. The first two are
  eager, because at ≥768px they are above the fold of that section on a typical laptop and
  a lazy-loaded above-the-fold image is a measurable LCP regression. `enhanced-img` emits
  `width`/`height`, so lazy loading causes no shift.
- **Hover:** the image scales to 1.03 inside its clipped box, 150ms ease, and the caption
  underlines. **No `translateY`, no shadow change.** The transform lives inside the
  component's own `@media (prefers-reduced-motion: reduce)` guard in addition to the global
  neutraliser.
- **Focus-visible:** the global 3px `focus-ring` at 2px offset on the `<a>`, never removed
  and never replaced by the hover scale.

**Caption and alt (05 D-25), the rule that matters:**
- `podpis` is the **visible caption** and names the room („Sala zabaw"). It is a
  `<figcaption>`, 15px Nunito 700 `ink`, 8px below the image, left-aligned.
- `alt` **describes what is in the photo** („Sala zabaw z kolorowymi zabawkami i dywanem").
  It is required at save time (Contract 8) and it is never the same string as the caption.
  This keeps 04.1 D-15 intact: alt stays a description, not a label.
- The link's accessible name is „Powiększ zdjęcie: " plus the alt, which disambiguates
  twelve otherwise identical links (WCAG 2.4.4) and is the same visually-hidden-prefix
  idiom the panel row actions already use.
- Polish alt text policy: a full sentence-fragment in Polish, no leading „Zdjęcie", no file
  name, no keyword list, and **never a person's name or a description that identifies a
  child**.

**Zero photos (required state).** The section, its `h2` and its `id` **always render**, so
the footer's `/o-nas#galeria` link can never break. Only the grid is conditional. With zero
photos the grid is replaced by the inherited empty-state panel (`--color-surface-warm`,
`--radius-md`, padding 24px, centred, Lucide `images` 32px `muted` `aria-hidden`, Baloo 700
20px heading, Nunito 400 16px `muted` body). Copy in the Copywriting Contract.

**One photo (required state).** The grid keeps its breakpoint column count and the single
tile occupies **one column**, never the full row. `justify-content: start`, and no
`auto-fit`/`auto-fill`, which would stretch a lone tile to the full container width and
make it read as a second hero competing with the page header.

**Twelve photos** is the hard editorial cap (05 D-23) and it is enforced in the panel and
at save time, not on the public page. The public page renders whatever the store holds.

### 2. Lightbox island (05 D-13)

The site's **fourth hydrated island** and the first on a content route. It must clear the
bar `MobileNav.svelte` set: bounded focus trap, Escape to close, focus restored,
`prefers-reduced-motion` honoured, its own axe AA pass **closed and open**.

**Progressive enhancement, and this is the whole reason the tile is a link.** Each tile is
an `<a href>` pointing at the full-size image asset in the prerendered HTML. With scripting
off the link opens the photo directly, which is a real working affordance. With scripting
on the island intercepts the click and opens the dialog. There is no conditional markup, no
button that does nothing without JavaScript, and no layout change on hydration.

- **The interception is narrow.** `preventDefault()` runs only for a plain primary-button
  click with no modifier key. Ctrl, Cmd, Shift, Alt and middle-click fall through to the
  browser, so „otwórz obraz w nowej karcie" keeps working. Keyboard Enter and Space on the
  link open the dialog.
- **Dialog:** `role="dialog"`, `aria-modal="true"`, `aria-labelledby` pointing at the
  caption element inside it. Rendered at the end of `<body>` via a portal-free
  fixed-position wrapper (no new dependency). Scrim `rgb(15 23 42 / 0.72)`, full viewport,
  `--color-surface` panel, `--radius-lg`, padding 16px, max-width `min(90vw, 60rem)`,
  max-height `90vh`.
- **Contents, in DOM order:** close button, image, caption (`h2`, Baloo 700 20px `ink`),
  alt description line (Nunito 400 13px `muted`, so the description is readable and not only
  announced).
- **Close button:** first focusable element, 44×44px, `--color-brand-blue` fill, white
  Lucide `x` 24px, `--radius-pill`, accessible name „Zamknij podgląd". Positioned inside
  the panel's top-right corner, never floating on the scrim alone.
- **Focus contract:** on open, focus moves to the close button. The trap is **bounded**
  (it cycles between the close button and the image container, exactly as `MobileNav`
  bounds its drawer) and never traps the page when the dialog is closed. On close, focus
  returns to the tile link that opened it. Body scroll is locked while open.
- **Escape closes.** A click on the scrim closes. The scrim click is never the only close
  affordance.
- **No navigation between photos.** No arrows, no swipe, no counter. Deferred by
  `05-CONTEXT.md` §Deferred Ideas, and recorded here so an executor does not invent it: a
  previous/next pair is a second focus-order problem, a second keyboard contract and a
  second set of Polish strings, for a twelve-photo set a visitor can close and reopen.
- **No preloading and no separate fetch.** The dialog renders the same responsive source
  the tile already has, at `sizes="(min-width: 1024px) 90vw, 100vw"`, so it normally paints
  from cache. **No spinner, no progress bar, no skeleton**, the same rule the panel photo
  island follows and for the same reason: a spinner is the easiest reduced-motion violation
  to ship by accident.
- **Motion:** opening is an opacity fade of 150ms on the scrim and the panel. Nothing
  translates, nothing scales. Inside `@media (prefers-reduced-motion: reduce)` the fade
  becomes an instant show and hide.
- **CSP:** no change. The island is same-origin and inline scripts already carry the
  per-response nonce from `kit.csp`. `kit.csp` must not be widened for it.

**Error state:** none. There is no runtime fetch, so there is nothing to fail. If an image
asset is missing the reader has already dropped that entry at build time (Contract 8's
reader rule), so the lightbox can never open onto nothing.

### 5. The amount formatter (05 D-35)

- **Location:** `src/lib/kwoty.ts`. In `$lib`, never `$lib/server`, because both the
  prerendered public page and the panel (a Cloudflare Worker) import it. This is the
  constraint already recorded three times, at `src/lib/zdjecia.ts:1-18`,
  `src/lib/stan-naboru.ts:1-28` and `src/lib/pola-strony.ts:1-30`.
- **Not plain `Intl`.** Verified in this repository on Node 25:
  `new Intl.NumberFormat('pl-PL').format(1500)` returns `"1500"` with no separator, because
  CLDR `pl` sets `minimumGroupingDigits=2` and both fee figures sit in the four-digit band
  where grouping is suppressed. A naive call silently turns the shipped `'1 500 zł'` into
  `'1500 zł'` and breaks `tests/home.spec.ts:112`. `src/lib/liczebniki.ts:12-16` already
  records the standing decision to avoid `Intl` in `$lib` for the same class of reason.
- **Hand-rolled grouping**, three digits from the right, so the function is pinnable
  byte-for-byte by a unit test rather than dependent on an ICU data version.
- **Separator: ASCII space (U+0020).** The shipped bytes of `OPLATY.kwota` are an ASCII
  space and `tests/home.spec.ts` retypes them. NBSP is typographically better and is
  **rejected**: the wrap it prevents is prevented instead by `white-space: nowrap` on the
  amount element, which is a CSS concern rather than a silent byte change under two
  retyped assertions.
- **Whole złoty only.** The store holds four digits maximum, no grosze, no separators. The
  uchwała quotes `2 337,00 zł`; the store drops the grosze rather than widening
  `liczbaWZakresie` in `src/lib/server/admin/walidacja/pola.ts`.
- **Unit test:** `tests/kwoty.unit.ts`, covering 0, 1, 999, 1000, 1500, 2337, 9999, and an
  assertion that the output of `1500` is byte-identical to the `1 500` inside the shipped
  `OPLATY.kwota`. Note the standing AG-3 gap: nothing automated runs `*.unit.ts`.

   into a property of the structure: the amount and its condition are one content block and
   cannot be separated. After handover nobody will call a developer when ZUS renames the
   benefit.
2. **The cross-field invariant `0 <= obnizka < stawka` must be hand-written.** The
   repository's only numeric validator, `liczbaWZakresie` in
   `src/lib/server/admin/walidacja/pola.ts:101-115`, accepts `/^[0-9]{1,4}$/` with an
   independent per-field min and max and **cannot express a relationship between two
   fields**. Without the invariant an editor can produce a negative payable amount, and the
   `0 zł` regex does not match `-837 zł`.
3. **A zero amount may occur only inside a string that also carries the ZUS condition.** This
   covers `zus`, `kwotaOpis`, `wyzywienie` and `nieobecnosc`, and it is also the rule that
   protects the computed homepage fee-tile suffix (Contract 7). The refusal names the field
   and says what to do.

**Note the unsatisfiable gate.** A literal `0 zł` grep is not a usable acceptance criterion,
because `1 500 zł` contains it (recorded at 04-06). The enforced form is a
boundary-anchored regex plus a rendered-text assertion, and this screen's validator uses the
same anchored shape.

**Store:** `src/lib/content/cennik.json` (panel-written, tab-indented, trailing newline,
byte-for-byte serialization pinned in the shape of `tests/admin-walidacja-nabor.unit.ts:172-190`).
`OPLATY` in `src/lib/content/rekrutacja.ts` becomes a **typed read of that store**, and the
module header at `:8-13` declaring the module code-authored only **must be rewritten in the
same commit** (05 D-03). The `/cennik` reservation comment at `:116-117` is resolved.
`/cennik` page prose that restates no amount lives in a separate `src/lib/content/cennik.ts`
(05 D-04).

**Cycle warning (05 D-03).** `rekrutacja.ts` already imports `site.ts`
(`import { urzad } from '$lib/content/site'`, line 23). Routing the homepage fee tile through
`OPLATY` would therefore create a cycle. **The tile must read the store, or a shared composer,
directly and never `OPLATY`.** And `OPLATY` is prose, not atoms: `kwota` is

## Motion & Reduced Motion

- Transitions stay 150 to 200ms `ease` on colour, border-colour, shadow, opacity and
  transform, matching Phase 1.
- **The two motions this phase introduces:** the gallery tile's 1.03 image scale on hover,
  and the lightbox's opacity fade on open and close. Both live inside component-scoped
  `@media (prefers-reduced-motion: reduce)` guards in addition to the global base-layer
  neutraliser in `app.css`. Under `reduce` the tile does not scale and the lightbox shows and
  hides instantly.
- **The lightbox animates nothing else.** No slide, no zoom-from-thumbnail, no crossfade
  between photos (there is no navigation between photos), no spinner, no skeleton.
- `/cennik` introduces no motion at all.
- The panel introduces no motion at all: the move buttons are server round trips and the
  page simply re-renders.
- No auto-scroll anywhere. Focus movement is the only thing that moves the viewport and it is
  always the result of an explicit action.

## Discretion Decisions Recorded (`05-CONTEXT.md` „Claude's Discretion")

These were mine to choose. They are recorded here so the planner implements them rather than
re-deciding them, and so the auditor can check them.

| Area | Decision |
|------|----------|
| Gallery filename prefix | **New `galeria-` prefix**, which is simultaneously the ownership marker. No `obiekt-` prefixed file exists in the repository, so the migration cost of a new prefix is zero and the honest naming is free |
| Gallery section heading | `Galeria: nasze miejsce`, so the footer link labelled „Galeria" and the „Nasze miejsce" framing both survive |
| Anchor and label attributes | `id="galeria"` carries the fragment; `aria-labelledby="galeria-heading"` points at the `h2`'s own id. The old `obiekt-heading` id is retired with the old heading |
| Lightbox trigger | The tile is an `<a href>` to the full-size asset, intercepted only on a plain unmodified primary click, so the no-JavaScript path is a real working affordance rather than a dead button |
| Lightbox scope | Single-photo enlargement only. No previous/next, no swipe, no counter, no preloading, no separate fetch |
| Lightbox scrim | `rgb(15 23 42 / 0.72)` built from the existing `ink` triple, matching how the shadow tokens already express it. No new hue |
| `/cennik` structure | Panels and `dl > div > dt/dd` rows, **never a `<table>`**, because a table splits an amount from its condition across cells at mobile width |
| `/cennik` desktop | The v1.6 §2 editorial split on every section from 2 to 7. No new layout idiom |
| Amount formatter | `src/lib/kwoty.ts`, hand-rolled grouping, ASCII space separator, whole złoty, `tests/kwoty.unit.ts`. `Intl` rejected (returns `"1500"` for `pl`), NBSP rejected (the shipped bytes are ASCII; wrapping is prevented with `white-space: nowrap`) |
| Nav density | The desktop nav's breakpoint moves from 768px to 1024px. Chip padding, gap, label size and the 44px target are all unchanged. **Provenance note:** unlike the other rows, this one is not drawn from the seven bullets of `05-CONTEXT.md` „Claude's Discretion". It is authorship filling a gap the discussion left open: D-16 fixes the nav at six items, and six chips do not fit at 768px without changing the locked chip geometry. Recorded here so the planner implements it, but an auditor should read it as a UI-SPEC decision, not a delegated one |
| `w-skrocie` arity | Four tiles, of which **two are read-only**: opłata (computed from Cennik) and wiek (statutory and duplicated in the Rekrutacja info card). This resolves both of D-33's drift hazards structurally instead of guarding them |
| Icon and tint unions | Stay **in code** as a fixed slot table zipped with the stored strings. No editor input can produce an icon key, so no editor typo can put `undefined` where a component is called |
| Opening hours | **Unified** across the tile, `contact.hours`, `TopBar`, `ContactAndMap`, `/kontakt` and the Footer literal, stored as four atoms with a composer in `src/lib/godziny.ts` |
| Placeholder flag | A **per-tile boolean** on `w-skrocie.json`, rendered as the existing „Treść zastępcza" checkbox, plus a named deliverable to extend the Phase 6 sweep to that boolean |
| Read-only presentation | Text plus a hint plus, where one exists, a link to the screen that owns the value. Never a `disabled` input |
| Panel nav order | Galeria after O nas (the page it renders on); Cennik after Plan dnia. W skrócie is a pulpit tile, not a nav item |
| Pulpit counters | Galeria gains „Liczba zdjęć: {n}"; Cennik and W skrócie carry none, so a fee amount is not rendered in a third place |
| Odpisy and nieobecność detail | One sentence each, taken from the store, with no invented rule. The full policy stays in the regulamin, which `/dokumenty` links |
| Basename-resolution idiom | Extract it. It is duplicated verbatim in three files today and this phase would make it four |
| Move-button end state | `disabled` rather than omitted, with a deterministic focus fallback, so the button row's geometry and the focus order stay stable as an editor works down the list |
