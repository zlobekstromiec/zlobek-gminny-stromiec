<objective>
Give the homepage fact tiles a store and an editor, and unify the opening hours.

Purpose: this is the "Ustawienia strony" work that Phase 04.1 deferred with the words "revisit
after Phase 5"; record it as the reversal of that deferral rather than as new scope. The
driving fact is that the opening hours are a live placeholder the żłobek cannot fix without a
developer, and they currently live on four surfaces with three sources: the tile, the shared
contact object, and a hard-coded literal in the footer. Making only the tile editable would
let an editor change the hours in the homepage strip while the footer of that same page kept
the old value.

Output: the store, the hours composer, the re-sourced tiles, the unified footer, the
fixed-arity panel screen, and the executable placeholder inventory.

## Slice capability (MVP)

After task 2 the homepage tiles and every surface stating the opening hours read one source,
and the footer can no longer disagree with the strip above it. After task 3 an editor can
change the hours and the number of places themselves.

## The checkpoint this plan is NOT taking

`05-UI-SPEC` Contract 7 records an alternative: exclude the hours from the editable set. That
would defeat the stated purpose of the screen, so it is a checkpoint decision to be taken in
the open and never a silent descope. This plan unifies the hours. If the unification proves
larger than it looks, stop and raise it rather than shipping a tile that disagrees with the
footer.

## Copy rules, hard, in every string this plan writes

Including code comments, test names and commit messages: no emoji, no em dashes anywhere (use
commas, colons, parentheses), en dash only inside a numeric range, plain hyphen in day
abbreviations. The opening-hours range is exactly the numeric-range case where the en dash is
correct, and the day abbreviation is exactly the case where a plain hyphen is correct; both
seed values are copied out of the existing modules rather than retyped, so neither can drift.
Polish only, on every visitor-facing and panel surface.
</objective>
