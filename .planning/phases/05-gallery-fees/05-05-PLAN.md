before adding the first of three new screens to them.

## Slice capability (MVP)

ROADMAP Phase 5 success criterion 3, in part, verbatim: *"Staff can ... edit the fees page
via the CMS, with changes publishing after a Cloudflare rebuild."*

permanently, and that gate is what makes tasks 2 and 3 safe. After task 2 an editor can find
Cennik in the panel navigation, open it, change a number and save. Task 1 is deliberately
GREEN on landing: it is a refactor plus a gate over the panel as it stands today, so that
adding the Cennik screen in task 2 turns it RED until every surface is edited. Writing the
gate red would have proved nothing about the existing seven screens.
