## Phase Goal

**As a** rodzic (parent), **I want to** read enrollment information, download the wnioski, and send an enrollment or contact message from the website, **so that** I can reach the żłobek and start the enrollment process without a visit, knowing my data is handled lawfully and never stored.

## MVP Slice (this plan)

**Go-live gate for both slices.** Plans 01 through 06 ship a fully working, fully tested pipeline that sends nothing real, because no external account exists yet. This plan provisions the external services, swaps the last placeholder, and proves with a real message that a parent's enrollment enquiry actually lands in the żłobek's mailbox. Until this plan completes, phase success criterion 2 is unproven.

Purpose: nothing in this phase is real until a message arrives in a real mailbox. Because nothing is stored, an undelivered submission is an application that never existed, which is why the delivery test is a phase gate and not a nice-to-have.
