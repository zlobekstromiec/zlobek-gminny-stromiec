## Phase Goal

**As a** rodzic (parent), **I want to** read enrollment information, download the wnioski, and send an enrollment or contact message from the website, **so that** I can reach the żłobek and start the enrollment process without a visit, knowing my data is handled lawfully and never stored.

## MVP Slice (this plan)

**Slice C (real data), plan 1 of 1, runs in parallel with Slice A.** After this plan a visitor on the homepage sees the żłobek's real address, real phone number, real age range, real fee and the real closed-nabor status, and sees an actual map of how to get there instead of a "coming soon" panel. That is user-visible value on its own, and it removes the fake facts before the two new pages start rendering the same objects in later waves.

|----------|-------------|
| source document -> published site copy | Facts move from a research digest into public municipal content. A wrong fact published by a public body is the real harm here, not a code exploit. |
| build machine -> tile.openstreetmap.org | A one-off outbound fetch during asset generation. Never at runtime, never from a visitor's browser. |
| visitor browser -> map | The map is a same-origin static image; no third-party request is made when a parent loads the page. |
