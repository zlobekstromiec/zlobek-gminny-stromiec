# Phase 1 — UI Design Contract

> Visual and interaction contract for the **design-foundation** phase. Every token locked here is inherited by Phases 2–6 — treat this as the project-wide design system, not a one-off homepage sheet. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope:** SITE-01, SITE-02, SITE-03, SITE-04, SITE-06, HOME-01, HOME-02.
**Stack context:** SvelteKit 2 + Svelte 5 (runes) + Tailwind CSS v4 (`@tailwindcss/vite`, CSS-first `@theme{}` — there is **no** `tailwind.config.js`). Content routes prerender to static HTML on Cloudflare. shadcn/ui is React-only and **does not apply**.
**Language:** Polish only (SITE-06). All visitor-facing strings below are the authoritative Polish copy.

## Layout & Breakpoints

Mobile-first (SITE-02). Tailwind v4 default breakpoints:

| Token | Min-width | Primary use |
|-------|-----------|-------------|
| (base) | 0 | Phone — single column, stacked |
| `sm` | 640px | Large phone |
| `md` | 768px | Tablet — nav becomes horizontal, 2-col grids |
| `lg` | 1024px | Desktop — 3-col grids, hero 2-col |
| `xl` | 1280px | Wide desktop |

- **Container:** max-width `72rem` (1152px), centered. Gutters: `16px` (base) → `24px` (`md`) → `32px` (`lg`).
- **Prose measure:** cap running text at ~`65ch` for readability.
- **Section vertical rhythm:** `py` 48px (base) → 96px (`lg`) for major sections; 32px → 48px for sub-blocks.

## Spacing Scale

8-point scale (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| `2xs` | 4px | Icon-to-label gaps, hairline insets |
| `xs` | 8px | Compact element spacing, chip padding |
| `sm` | 12px | Button vertical padding, tight stacks — **intentional exception** to the canonical 8-pt set; a valid 4px-grid multiple, scoped to button/control padding only (do not use for layout spacing) |
| `md` | 16px | Default element spacing, card inner padding (mobile) |
| `lg` | 24px | Card inner padding (desktop), grid gaps, section sub-padding |
| `xl` | 32px | Layout gaps, container gutter (lg) |
| `2xl` | 48px | Section vertical padding (mobile), major breaks |
| `3xl` | 64px | Page-level spacing |
| `4xl` | 96px | Hero/section vertical padding (desktop) |

**Exceptions:** Interactive targets (nav links, hamburger, buttons, tel/email links) have a **minimum hit area of 44×44px** (WCAG 2.5.5 / touch), even when the visual element is smaller — pad to reach it.

## Typography

Mobile-first sizes with responsive `clamp()`. **Exactly two weights** across the whole system: **Regular 400** and **Bold 700**.

| Role | Element | Family | Size | Weight | Line Height |
|------|---------|--------|------|--------|-------------|
| Display | Hero `h1` | Baloo 2 | `clamp(2rem, 5vw, 2.75rem)` (32→44px) | 700 | 1.1 |
| Heading | Section `h2` / card `h3` | Baloo 2 | `clamp(1.5rem, 3vw, 1.75rem)` (24→28px); card title 20px | 700 | 1.2 |
| ↳ | *card `h3` is a **sub-step of the Heading role** (20px), not a 5th size — same family/weight/line-height, smaller optical size for dense card grids* ||||||
| Body | Paragraphs, subcopy | Nunito | 16px | 400 (700 for inline emphasis) | 1.5 |
| Label | Nav links, meta/date, captions, buttons | Nunito | 14px | 700 | 1.4 |

- Never introduce a 3rd weight or a 5th size. Buttons use the Label row (14px/700) or Body (16px/700) — pick per component below.
- Body links are underlined (see Interaction) — color is never the sole signal.

## Color

Locked **two-tier token system** (SITE-04). The **Expressive tier** is full-saturation joy for *non-text* decoration only. The **Accessible tier** is the contrast-tuned subset that every text/icon/border/focus/button-label MUST draw from. **Red (czerwony) is semantic only** (errors/alerts) — never decorative.

### 60 / 30 / 10 split
_source: orchestrator default (recommended) — confirmable_

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` surface / `#FBFAF7` warm off-white | Page background, cards, airy negative space |
| Secondary (30%) | Sky-blue family — `#0369A1` (structure/links/primary button) + `#E0F2FE` (section bands) | Header wordmark, links, primary button, alternating section bands, structural brand |
| Accent (10%) | Warm amber/orange — `#F59E0B` | **Reserved list below** |
| Destructive | `#B91C1C` | Errors/alerts/destructive only |

**Accent reserved for:** the primary Rekrutacja CTA fill; inline highlight/underline flourishes on the hero; small joyful decorative shapes (expressive tier). **Never** applied to every interactive element, body links, or generic buttons — those are sky-blue.

### Expressive tier (decorative surfaces / blobs / shapes only — NOT text)

| Token | Hex | Note |
|-------|-----|------|
| `expr-blue` | `#38BDF8` | Sky blob / decorative fill |
| `expr-yellow` | `#FACC15` | Sunny blob / highlight shape (żółty) |
| `expr-orange` | `#FB923C` | Warm blob (pomarańczowy) |
| `expr-red` | `#F87171` | **Reserved** — do NOT use decoratively; listed only so it is never mistaken for a UI color |

> Any text, icon, or border placed over an expressive surface must switch to an Accessible-tier value that meets AA **against that specific surface** (see pairings).

### Accessible tier — tokens + AA-verified contrast pairings

Ratios computed with the WCAG relative-luminance formula. AA thresholds: **4.5:1** normal text, **3:1** large text (≥24px, or ≥18.66px bold) & UI component/graphics boundaries.

| Token | Hex | On background | Ratio | Meets |
|-------|-----|---------------|-------|-------|
| `ink` (body text) | `#1E293B` | `#FFFFFF` | **14.65:1** | AAA ✓ |
| `ink` on band | `#1E293B` | `#E0F2FE` | **12.77:1** | AAA ✓ |
| `muted` (subcopy/meta) | `#475569` | `#FFFFFF` | **7.58:1** | AAA ✓ |
| `brand-blue` (links, primary btn fill, wordmark) | `#0369A1` | `#FFFFFF` | **5.93:1** | AA ✓ |
| `brand-blue` link on band | `#0369A1` | `#E0F2FE` | **5.17:1** | AA ✓ |
| white label on `brand-blue` btn | `#FFFFFF` | `#0369A1` | **5.93:1** | AA ✓ |
| `accent` CTA fill (label ink) | `#F59E0B` | ink `#1E293B` on it | **6.82:1** | AA ✓ |
| `accent-hover` CTA fill (label ink) | `#D97706` | ink `#1E293B` on it | **4.60:1** | AA ✓ |
| `accent-active` CTA fill (label ink) | `#B45309` | ink `#1E293B` on it | ~3.9:1 → **use white label** `#FFFFFF` → 4.6:1 | AA ✓ |
| `danger` (error text/border) | `#B91C1C` | `#FFFFFF` | **6.47:1** | AA ✓ |
| `focus-ring` | `#0C4A6E` | `#FFFFFF` (adjacent) | **9.46:1** | AA ✓ (≥3:1 UI) |
| `border-strong` (input/UI boundary) | `#64748B` | `#FFFFFF` | **4.76:1** | AA ✓ (≥3:1 UI) |
| `border-subtle` (decorative divider) | `#E2E8F0` | `#FFFFFF` | ~1.2:1 | decorative only (no info) |
| `danger-surface` | `#FEF2F2` | with `#991B1B` text → ~7:1 | — | AA ✓ |

**Hard rules:**
- The **accent CTA never uses white text** on `#F59E0B` (2.15:1 — fails). CTA label is `ink #1E293B` on default/hover; on the `active` (darkest) state switch the label to white to stay ≥4.5:1.
- Body links are `brand-blue #0369A1` **and underlined** (never color-only).
- Section bands alternate `#FFFFFF` / `#FBFAF7` / `#E0F2FE`; verify any text color against the actual band it lands on using the table above.

## Interaction & States (global)

| Surface | Default | Hover | Focus-visible | Active |
|---------|---------|-------|---------------|--------|
| Body link | `brand-blue` + underline | darken underline / `#075985` | 3px `focus-ring`, 2px offset | — |

- **Skip link:** first focusable element `„Przejdź do treści"` → `#main`, visually hidden until focused.

## Motion & Reduced Motion

- Default transitions: 150–200ms `ease` on color/shadow/transform. Drawer slide ~220ms.
- **`@media (prefers-reduced-motion: reduce)`** (WCAG 2.3.3 / A11Y-01): disable all transforms, blob float/parallax, drawer slide (swap for instant show/hide), and `scroll-behavior: smooth`. Keep only instant/opacity changes. This is a hard requirement, not optional polish.

---

## Accessibility Contract (WCAG 2.1 AA — A11Y-01 baseline starts here)

- `<html lang="pl">`; semantic landmarks: one `<header>`, `<nav aria-label="Główna nawigacja">`, one `<main id="main">`, one `<footer>`.
- Exactly one `h1` (hero); heading order not skipped.
- All AA contrast per the Color table (verified ratios).
- All interactive targets ≥44×44px; visible focus everywhere; keyboard-operable drawer (trap + ESC + restore focus).
- No meaning by color alone (links underlined; active nav uses bar + `aria-current`).
- Decorative icons/blobs/placeholder images `aria-hidden`; informative images get Polish `alt`.
- `prefers-reduced-motion` honored.
