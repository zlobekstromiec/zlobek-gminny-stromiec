<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| git content -> build reader | Post JSON is authored by staff via the CMS (Plan 03) or seeded here; the build reader consumes it. Untrusted-ish content (a compromised editor account) crosses into the prerender. |
| obraz field -> filesystem glob | The cover field names an image; NewsCard resolves it by basename against a static glob set, never by arbitrary path. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-03 | Tampering | NewsCard cover resolution (obraz) | low | mitigate | Resolve covers by basename against import.meta.glob('$lib/assets/uploads/*'); an unknown basename yields the tint fallback, never a filesystem read of an arbitrary path (no traversal). |
| T-03-04 | Denial of Service | src/lib/server/aktualnosci.ts reader | low | mitigate | Skip a malformed entry (bad date or bad slug) with console.warn and continue; one bad post never aborts the whole prerender (dokumenty.ts precedent). |
| T-03-SC | Tampering | npm/pip/cargo installs | low | accept | No package installs this phase; all deps (marked, enhanced-img, sveltia, lucide) are pinned from Phase 2. RESEARCH Package Legitimacy Audit records zero new/[SUS]/[SLOP] packages, so no legitimacy checkpoint is required. |
</threat_model>
