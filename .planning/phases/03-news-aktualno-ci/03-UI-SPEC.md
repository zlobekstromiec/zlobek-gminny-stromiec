# Phase 3 — UI Design Contract

> Visual and interaction contract for the **News (Aktualności)** phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **This is a delta spec.** The project-wide design system is LOCKED in Phase 1 (`01-UI-SPEC.md` + Amendments v1.1/v1.2). Every token, type size, weight, color, radius, shadow, spacing value, motion rule, and accessibility rule is inherited **verbatim and unchanged**. This document adds ONLY the new surfaces this phase introduces:
> 1. `/aktualnosci` news-list page (NEWS-01)
> 2. `/aktualnosci/[slug]` single-post page (NEWS-02)
> 3. Homepage `NewsPreview` realignment — wire the locked card contract to the real CMS feed (HOME-02)
> 4. CMS `aktualnosci` folder collection — Polish copy contract at `/admin` (NEWS-03)
>
> **Do NOT re-derive colors, type, spacing, or components.** Where this spec is silent, the Phase 1 contract governs.

**Scope:** NEWS-01, NEWS-02, NEWS-03.
**Stack context:** SvelteKit 2 + Svelte 5 (runes) + Tailwind CSS v4 (`@tailwindcss/vite`, CSS-first `@theme{}` — there is **no** `tailwind.config.js`). Both new routes prerender to static HTML on Cloudflare (zero-JS, consistent with existing content pages). shadcn/ui is React-only and **does not apply**. The CMS admin (`/admin`) is a self-hosted Sveltia SPA — outside SvelteKit routing and outside this design system.
**Language:** Polish only (SITE-06, CMS-03). All strings below are the authoritative Polish copy. **Copy rules (locked, v1.2 §8):** no emoji; no em dashes in authored copy or comments; en dash only inside numeric ranges; day abbreviations use plain hyphen (pon.-pt.); use commas, colons, and parentheses instead of em dashes.

## Spacing Scale

**Inherited unchanged from Phase 1.** No new spacing tokens. The two new routes use the established rhythm:

- Page section vertical padding: `48px` (base) → `64–96px` (`lg`), matching existing content sections (`NewsPreview` already uses 48→96).
- Container: max-width `72rem`, centered, gutters `16px` → `24px` (`md`) → `32px` (`lg`).
- Card grid gap: `24px` (inherited news-grid value).
- Single-post prose measure: running body capped at **~65ch** (inherited prose rule); the article column sits inside the container, not full-bleed.
- Card inner padding: `16px` (mobile) → `24px` (desktop) (inherited card value).

**Exceptions:** Interactive targets (card links, „Zobacz wszystkie", back link, tel/mail links in body) keep the **minimum 44×44px hit area** (WCAG 2.5.5). The whole card is a single link with an effective tap area well above 44px.

## Typography

**Inherited unchanged from Phase 1 (+ Amendments v1.1/v1.2).** Exactly two weights (Regular 400, Bold 700); two families (Baloo 2 display, Nunito body). No new sizes — the inherited scale (locked h1/h2 clamps + 13/14/15/16/17/19/20/26px) covers every element on both new pages.

Role mapping for the new surfaces (all drawn from the inherited scale):

| Element | Family | Size | Weight | Line Height |
|---------|--------|------|--------|-------------|
| List page title (`h1` „Aktualności") | Baloo 2 | `clamp(2rem, 5vw, 2.75rem)` (locked h1 clamp) | 700 | 1.1 |
| List page lead | Nunito | 19px | 400 | 1.55 |
| Single-post title (`h1`) | Baloo 2 | `clamp(2rem, 5vw, 2.75rem)` (locked h1 clamp) | 700 | 1.1 |
| Post date meta (list + card + post header) | Nunito | 14px | 700 | 1.4 |
| Card title (`h3`, whole card is the link) | Baloo 2 | 20px | 700 | 1.2 |
| Card excerpt (`zajawka`, line-clamped) | Nunito | 15–16px | 400 | 1.5 |
| Post body paragraphs | Nunito | 16px | 400 (700 inline emphasis) | 1.5 |
| Post body list items | Nunito | 16px | 400 | 1.5 |
| Back / „Zobacz wszystkie" link | Nunito | 14px | 700 | 1.4 |

- Never introduce a 3rd weight or a size outside the inherited scale. Italic is **not** available (no italic WOFF2 face is loaded — 400/700 upright only); the constrained markdown widget therefore omits italic to prevent faux-italic synthesis.
- Post body renders a **limited markdown subset only** (paragraphs, bold, links, bulleted list, numbered list) via `marked` + sanitize (see Component Contracts). **No headings, no inline images, no tables, no raw HTML** reach the DOM, so the locked type hierarchy (post `h1` is the only heading in the article) stays intact. Bold renders as Nunito 700; links follow the inherited body-link rule (brand-blue + underline).

**Inherited unchanged from Phase 1.** The locked two-tier token system (Expressive/decorative vs Accessible text-UI), the 60/30/10 split, and every AA-verified pairing govern both new pages. **No new color tokens.** Reference table for the elements this phase adds:

|------|-------|---------------------------|
| Dominant (60%) | `#FFFFFF` / `#FBFAF7` warm | List-page and article backgrounds; card surface `#FFFFFF`; the list section band matches `NewsPreview` (`--color-surface-warm`) |
| Secondary (30%) | `#0369A1` brand-blue + `#E0F2FE` band | Card title link, date meta structure, „Zobacz wszystkie" / back links, body links inside a post |
| Accent (10%) | `#F59E0B` amber | Reserved list unchanged. On these pages accent appears **only** as: an optional single decorative chip/flourish, the imageless-card tint fallback icon stroke context, and (inherited) the `Zapisz dziecko` CTA if a closing CTA is surfaced. **Card titles, date meta, and read-more/back links are brand-blue, never accent.** |

## Component Contracts (NEW this phase)

### `/aktualnosci` news-list page (NEWS-01) — prerendered, zero-JS

**Route:** `src/routes/aktualnosci/+page.svelte` (+ `+page.server.ts` for the build-time feed read). **Remove `/aktualnosci` from `svelte.config.js` `KNOWN_FUTURE_ROUTES`** when the route lands, so the prerender crawler enforces it. Entries: folder collection `src/lib/content/aktualnosci/*` read at build (`import.meta.glob`), **sorted by `data` descending (newest first — NEWS-01)**. Reuses `Seo`, `Header`, `Footer`, `TopBar`, `SkipLink`, `Cta`.

**Primary visual anchor:** the newest-first card grid is the page's focal element; the header lead and any decorative flourish stay subordinate.

**Composition:**
1. **Page header** — `h1` „Aktualności" on `#FFFFFF`; short lead paragraph (Nunito 19px `muted`, ≤56ch) explaining the section (see Copywriting). Optional single decorative expressive flourish, `aria-hidden`.
2. **Card grid** — responsive `1 col (base) → 2 (md) → 3 (lg)`, gap `24px`, on `--color-surface-warm` band (mirrors `NewsPreview`). Cards sorted newest-first.
3. **EMPTY STATE (required — this is where the inherited empty state lives, per Amendment v1.1 §1):** when the collection has zero posts, replace the grid with the friendly panel already shipped in `NewsPreview.svelte` (`#FFFFFF` card, `1px border-subtle`, `radius-md`, centered, Lucide `newspaper` 40px `brand-blue` `aria-hidden`):
   - Heading (Baloo 20px/700 `ink`): „Wkrótce pojawią się aktualności"
   - Body (Nunito 16px `muted`): „Nie opublikowaliśmy jeszcze żadnych wpisów. Zajrzyj tu wkrótce, będziemy informować o wydarzeniach i nowościach z życia żłobka."

**Pagination:** none in v1. The list renders **all** posts newest-first (post volume is low for a municipal żłobek). Pagination / filtering is explicitly deferred (v2 `NEWS-04`) to keep the page zero-JS and prerendered.

### News card — **inherited card contract from Phase 1 §Latest-Aktualności preview, now bound to real data**

Reuse the locked card definition (single shared card component used by both `/aktualnosci` and the homepage `NewsPreview`):

- **The whole card is one `<a>`** → `/aktualnosci/{slug}` (title is inside it; screen reader announces cover-alt + title + date + excerpt together).
- **Cover (top):** `16:9`, `radius-sm`.
  - If the post has an `obraz` (cover image): render via `@sveltejs/enhanced-img` (`<enhanced:img>`, responsive AVIF/WebP srcset, width/height to prevent CLS) with the post's informative Polish `alt`.
  - **If no cover image:** decorative tint fallback panel (one `--color-tint-*` surface, `radius-sm`) carrying one existing bespoke icon chip (46px, brand-blue stroke, per v1.2), `aria-hidden` — so imageless cards stay visually consistent in the grid and never render a bare box. The accessible signal is the title + date text.
- **Date label:** Nunito 14px/700 `muted`, rendered inside a `<time datetime="YYYY-MM-DD">` element; optional Lucide `calendar` 16px `aria-hidden`. Display format: long Polish date „1 sierpnia 2026" (see Copywriting — date formatting note).
- **Title (`h3`):** Baloo 2 20px/700 `brand-blue`, underlined-on-hover (whole card is the link).
- **Excerpt:** the `zajawka` field, Nunito 15–16px `muted`, **2–3 line clamp** (`-webkit-line-clamp`); falls back to the first paragraph of the body when `zajawka` is empty.
- **States (inherited):** rest `shadow-md`; hover `shadow-lg` + `translateY(-2px)`; focus-visible 3px `focus-ring` 2px offset on the card link. All transforms inside the card's local `prefers-reduced-motion` block.

### `/aktualnosci/[slug]` single-post page (NEWS-02) — prerendered, zero-JS

**Route:** `src/routes/aktualnosci/[slug]/+page.svelte` (+ `+page.server.ts` with `entries()` returning every post slug so all posts prerender to static HTML). A missing slug returns SvelteKit `error(404)` (prerender crawler only visits real slugs). Reuses the shared layout chrome.

**Composition (single `<article>` inside `<main id="main">`):**
1. **Post header** — `h1` = post `tytul` (locked h1 clamp) on `#FFFFFF`; date meta directly under it (Nunito 14px/700 `muted`, Lucide `calendar` `aria-hidden`, wrapped in `<time datetime>`).
2. **Cover image (optional)** — if `obraz` is set: `enhanced-img`, `radius-lg`, informative Polish `alt`, width/height (no CLS). Sits between header and body, full article-column width. Omitted cleanly when absent (no placeholder box on the article page).
3. **Body** — the `tresc` markdown field rendered via `marked` + **sanitize** (consistent with the committed WR-03 inline-sanitize approach; here it is a **full** `marked` parse, not `parseInline`, because a post has multiple block elements). Constrained to paragraphs, bold, links, bulleted list, numbered list. Prose measure ~65ch; body 16px/1.5 `ink`; bold Nunito 700; links `brand-blue` underlined (inherited body-link states); lists use default disc/decimal markers with comfortable inset. No headings/images/tables/raw-HTML reach the DOM.
4. **Back link (footer of article)** — „Wszystkie aktualności" → `/aktualnosci`, Nunito 14px/700 `brand-blue` underlined, optional Lucide `arrow-left` `aria-hidden`, 44px target.
5. **Closing CTA (optional, inherited):** the `Zapisz dziecko` primary CTA → `/rekrutacja` may close the article (reuses `Cta` primary variant, all inherited states). No new button styling.

**No empty state on the single-post page:** the route only exists for real slugs; an unknown slug is a 404, not an empty render.

No new visual contract. `NewsPreview.svelte` already renders the locked card/empty-state design. - The homepage still renders `NewsPreview` **only when `posts.length > 0`** (Amendment v1.1 §1 — the homepage never shows the news empty state; that lives on `/aktualnosci`).
- Curated count: the most recent **3** posts (matches the 3-col grid); exact cap is a planner detail but MUST fill whole grid rows cleanly and stay a small subset.
- Card links now point to `/aktualnosci/{slug}`; the section „Zobacz wszystkie" link already targets `/aktualnosci`.
- Section order on the homepage is unchanged (Aktualności renders after ContactAndMap, only when posts exist — Amendment v1.1 §1).

> **Test lockstep:** `tests/home.spec.ts` asserts the homepage news behaviour (currently: `NewsPreview` absent while `posts` is empty). Add `tests/aktualnosci.spec.ts` (list + a single post) with `@axe-core/playwright` asserting zero AA violations, including the newest-first order (NEWS-01) and full-content render (NEWS-02).

### CMS `aktualnosci` folder collection (NEWS-03) — Sveltia SPA, NOT a site-authored surface

`/admin` is the self-hosted Sveltia bundle (`static/admin/`), outside SvelteKit routing and outside this design system. This spec does **not** style it — Sveltia owns the editor chrome. What this phase DOES own is the **Polish copy contract** for the new collection's labels/hints in `config.yml`, plus the inherited locale caveat. See the CMS Polish Copy Contract below.

- New **folder collection** `aktualnosci` (`folder: src/lib/content/aktualnosci`, `create: true`), mirroring the established `dokumenty` collection pattern (per-collection config; images go to the Vite-processed `media_folder: src/lib/assets/uploads` so `enhanced-img` can optimize covers, NOT `static/` — Pitfall 4).

There is **no site-authored destructive confirmation to design** — Sveltia provides its own confirm dialog (English chrome). The CMS instrukcja documents the flow with annotated Polish screenshots (mirrors the D-21 Phase 2 pattern).

## Accessibility Contract (WCAG 2.1 AA — inherited baseline extends to both new routes)

- `<html lang="pl">`; each page has exactly one `<h1>` (list: „Aktualności"; post: the post title) and correct heading order. On the list page cards use `<h3>` — this **skips `h2`**, so cards MUST sit under a visually-hidden or present `h2` section wrapper (e.g. `<section aria-label="Wpisy">` with the cards, or promote card titles to `h2`). **Planner decision, but no skipped heading levels may ship** — either give the grid an `h2` or make card titles `h2`. On the single-post page the article body renders **no** headings (constrained markdown), so the post `h1` is the only heading.
- Landmarks via shared layout: one `<header>`, `<nav aria-label="Główna nawigacja">`, one `<main id="main">`, one `<footer>`. The single post is wrapped in `<article>`.
- Post date uses `<time datetime="YYYY-MM-DD">` for machine-readable dates.
- All contrast per the inherited Color pairings; verify text over any band/tint against the actual surface.
- Every card/link ≥44px hit area; the whole card is one link (no nested interactive elements inside it).
- No meaning by color alone (links underlined; date is text, not just a calendar icon).
- Cover images get informative Polish `alt`; the imageless-card tint fallback + its icon chip and any decorative flourish are `aria-hidden`. `enhanced-img` emits width/height (no CLS).
- Each new route has a Playwright + `@axe-core/playwright` spec asserting zero AA violations (`tests/aktualnosci.spec.ts` covering the list, a single post, and the empty state).
- **CMS-03 caveat (inherited, must be acknowledged, not silently accepted):** Sveltia's editor chrome (Save/Publish/menus) ships **English + Japanese only** — Polish is not an available UI locale as of 2026-08-13. All config-driven text (labels/hints) for the new `aktualnosci` collection IS Polish. The CMS instrukcja carries annotated Polish screenshots for the news-publishing flow. Re-verify Sveltia's shipped locale list against the pinned bundle at build.
