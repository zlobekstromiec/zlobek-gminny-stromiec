## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| staff-authored tresc -> prerendered DOM | Post body Markdown (authored via CMS or a compromised editor account) is rendered into static HTML. This is the primary stored-XSS boundary of the phase. |
| post cover obraz -> filesystem glob | Cover resolved by basename against a static glob, never by arbitrary path. |
| external link in post body -> visitor browser | A link in the body could point at a hostile scheme; the renderer allow-lists safe protocols. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering / Elevation | renderPost (post body Markdown) | high | mitigate | Hardened full-block renderer: escape raw HTML, drop images to alt text, neutralize headings and GFM tables, allow-list link protocols via SAFE_HREF; no raw HTML/script/javascript:/data: reaches the DOM. Second layer: page CSP script-src 'self' (svelte.config.js). Two-layer defense per D-08/WR-03. |
| T-03-02 | Tampering | renderPost link handling | medium | mitigate | SAFE_HREF allow-list (http(s)/mailto/tel/relative/fragment only); an unsafe href renders as plain text, never an anchor. |
| T-03-03 | Tampering | [slug] cover resolution (obraz) | low | mitigate | Resolve the cover by basename against the static uploads glob; an unknown basename omits the cover, never a filesystem read of an arbitrary path. |
| T-03-SC | Tampering | npm/pip/cargo installs | low | accept | No package installs this phase; all deps pinned from Phase 2 (RESEARCH Package Legitimacy Audit: zero new/[SUS]/[SLOP]). No legitimacy checkpoint required. |
