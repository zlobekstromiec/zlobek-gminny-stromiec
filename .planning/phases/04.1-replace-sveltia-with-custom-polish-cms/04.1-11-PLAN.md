<objective>
Prove the new panel on the live deployment with a real person, then remove the old editor in one clean sweep, including the two pieces of live service configuration that no grep can see.

Purpose: D-20 makes this ordering non-negotiable. If the panel has a defect, staff must still have a working editor rather than none, and the site is about to go public. This plan is therefore the phase's gate and its closing act at the same time.

Output: a recorded UAT, a repository with no trace of the old editor, a deleted OAuth App and a deleted auth Worker, reworded requirements, and a green suite proving the public site never noticed.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| removed repository files to live service configuration | deleting a file does not revoke a credential or stop a deployment |
| the old OAuth App to the repository | until deleted it remains an authorization path into the same repository the new App writes to |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04.1-38 | Elevation of Privilege | an orphaned OAuth App still able to authorize access to the repository | high | mitigate | Task 3 deletes it in the GitHub UI, with an explicit instruction distinguishing it from the new App, and the deletion is verified by its absence from the list. |
| T-04.1-39 | Spoofing | a still-deployed auth Worker answering on a public hostname after its source is gone | medium | mitigate | Task 3 deletes the deployment and records the observed response from the hostname afterwards. |
| T-04.1-40 | Denial of Service | removing the only working editor before the replacement is proven | high | mitigate | D-20 and P-30: the removal is gated on a passing live UAT with a real staff member, and the repository sweep precedes the service deletion. |
| T-04.1-41 | Tampering | loosening the site content policy to accommodate the panel during the sweep | medium | mitigate | Explicitly prohibited, and enforced by a diff assertion on the framework config. |

| T-04.1-SC | Tampering | npm/pip/cargo installs | high | mitigate | This plan installs nothing; it REMOVES one dev dependency and regenerates the lockfile. The phase's net supply-chain movement is a reduction. |
