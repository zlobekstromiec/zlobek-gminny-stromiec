## Pattern Assignments

### `src/lib/server/admin/kod.ts` (service, KV CRUD)

**Analog:** `src/lib/server/forms/ratelimit.ts` — read it whole (179 lines) before writing this file.

**Key-derivation pattern** (`ratelimit.ts:60-73`) — copy the salted-digest shape verbatim, change the prefix to `adm:`:

```ts
export async function kluczLimitu(
	formularz: string, ip: string, sol: string, teraz: number
): Promise<string> {
	const bajty = new TextEncoder().encode(`${sol}:${formularz}:${ip}`);
	const skrot = await crypto.subtle.digest('SHA-256', bajty);
	const hex = [...new Uint8Array(skrot)]
		.slice(0, 8)
		.map((bajt) => bajt.toString(16).padStart(2, '0'))
		.join('');
	return `rl:${formularz}:${hex}:${kubelekGodzinowy(teraz)}`;
}
```

**Injected-clock rule** (`ratelimit.ts:41-50, 99-107`): `teraz: number` is a **required or last-positional** parameter with no second clock read inside. `tests/forms.unit.ts` depends on this to freeze time. The OTP TTL and burn logic must follow it.

**KV guard + fail-open pattern** (`ratelimit.ts:108-113, 128-131, 156-178`):

```ts
if (!kv) {
	console.warn('ratelimit: brak wiazania FORMS_KV, limit nieaktywny');
	return true;
}
...
if (sol.trim().length === 0) {
	console.warn('ratelimit: brak RATE_LIMIT_SALT, limit nieaktywny');
	return true;
}
...
try {
	const biezace = licznik(await kv.get(klucz));
	...
	await kv.put(klucz, String(biezace + 1), { expirationTtl: MNOZNIK_TTL * OKNO_S });
} catch {
	console.warn('ratelimit: operacja KV nieudana, limit nieaktywny dla tego zgloszenia');
	return true;
}
```

**Divergence the planner must decide (do not copy blindly):** the OTP store must **fail closed**, not open. `ratelimit.ts` fails open because it is an abuse control behind Turnstile; `kod.ts` is the authentication boundary itself. A KV failure must refuse the login with the „Nie udało się" panel, never grant a session. Every `console.warn` in this file names bindings and never the address (RODO rule, `sanitize.ts:1-8`).

**Shared-daily-counter coupling (Pitfall 6):** `podLimitem()` uses `PREFIKS_DOBOWY = 'rl:doba'` site-wide (`ratelimit.ts:23, 42-44, 160-161`). Reuse `podLimitem(kv, 'admin-kod', ip, sol, limit, limitDobowy, teraz)` and pass an explicit `limitDobowy` — do not leave it at `DOMYSLNY_LIMIT_DOBOWY = 40`, which is the forms' Resend budget guard.

### `src/lib/server/admin/github.ts` and `mail-kod.ts` (service, external HTTP)

**Analog:** `src/lib/server/forms/mailer.ts` (142 lines).

**Raw fetch, no SDK** (`mailer.ts:116-142`):

```ts
try {
	const res = await fetch(RESEND, {
		method: 'POST',
```

**Dry-run seam** (`mailer.ts:123-125`): `if (dryRun) return true;` driven by `FORM_DRY_RUN === '1'`, set only by `preview:test` bindings. Reuse it for the login mail so Playwright never sends.

## Shared Patterns

### 1. Secrets access
**Source:** `src/routes/api/kontakt/+server.ts:6-10, 29-33, 50-61`
**Apply to:** `hooks.server.ts` and every admin `+page.server.ts`.
```ts
const env = platform?.env;
if (!env?.RESEND_API_KEY || !env?.TURNSTILE_SECRET_KEY) {
	return json({ ok: false, code: 'wysylka' }, { status: 502 });
}
```
The Vite build-time env object is grep-banned across server code and is therefore never written, only described in a comment.

### 2. Nothing personal is logged
**Source:** `src/lib/server/forms/sanitize.ts:1-8`, `mailer.ts:7`, `ratelimit.ts:174-176`
**Apply to:** every module under `src/lib/server/admin/`.
A staff e-mail address is personal data on a public body's system (RODO, C-03). `console.warn` names bindings and status codes only, never a value, never an address, never an error object interpolation.

### 3. Documented degrade with an explicit direction
**Source:** `ratelimit.ts:108-131` (fail open), `mailer.ts:137-141` (fail as failure)
**Apply to:** every admin failure branch. Each branch must state in a comment which direction it fails and why. The admin rule differs from the forms rule: **auth fails closed, the write path reports the real outcome, the rate limiter alone may fail open.**

### 4. Pure module + injected side effects = unit-testable
**Source:** `handle.ts:1-28`, `sanitize.ts:1-8`
**Apply to:** `serializuj.ts`, `slug.ts`, `walidacja.ts`, `allowlist.ts` (pure); `commit.ts`, `github.ts`, `kod.ts` (injected `fetch` / `kv` / `teraz`).

### 5. Comment-as-contract
**Source:** every file read for this map
This codebase encodes the *reason* for each constraint in a comment next to the code, including "why this is NOT written here" for grep-banned strings (`kontakt/+server.ts:6-10`, `mailer.ts:112-114`, `svelte.config.js:20-24`). New admin modules must do the same; a grep gate that a comment would break is a real hazard here.

### 6. Copy rules apply to code, tests and commit messages
**Source:** `site.ts:5`, `forms-copy.unit.ts`, UI-SPEC v1.2 §8
No emoji, no em dashes, en dash only in numeric ranges — including comments, Polish test titles and the D-04 commit message. `coreMessage` (`site.ts:12`) is the single documented byte-exemption.

### 7. Polish-only, single-source copy module
**Source:** `src/lib/content/forms.ts` + `tests/forms-copy.unit.ts`
**Apply to:** all panel copy. Put every authoritative string from the UI-SPEC Copywriting Contract in one exported module and sweep it recursively, including the OTP mail body.
