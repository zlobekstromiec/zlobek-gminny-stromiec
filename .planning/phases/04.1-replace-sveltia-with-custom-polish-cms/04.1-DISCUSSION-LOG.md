# Phase 04.1: Replace Sveltia with custom Polish CMS - Discussion Log

> **Audit trail only.** Do not use as input to planning, research, or execution agents.
> Decisions are captured in CONTEXT.md; this log preserves the alternatives considered.

**Date:** 2026-08-15
**Phase:** 04.1-replace-sveltia-with-custom-polish-cms
**Areas discussed:** Logowanie kodem e-mail, Write path, Zdjęcia (upload i okładki), Panel (zakres i obsługa), Migracja i wymagania

**User constraint raised during area selection:** keep cost as low as possible, free if at all possible. Checked against every option below. All candidate options were free, so cost did not act as a tiebreaker; it did surface two ceilings that shaped decisions (500 Pages builds per month, roughly 10 ms Workers CPU per request).

## Logowanie kodem e-mail

### Auth mechanism

| Option | Description | Selected |
|--------|-------------|----------|
| Self-built kod e-mail | Own login on the existing Resend + FORMS_KV + rate-limiter stack; everything Polish and in the repo; owns code expiry, attempt limits and cookie security | ✓ |
| Cloudflare Access OTP | Edge gate, free to 50 users, no code-generation or session work; but Cloudflare's login page, uncertain Polish localisation, dashboard config outside the repo, dev and preview bypass needed | |
| Access as outer gate, own panel inside | Both layers; strongest defence in depth but inherits the login-screen language risk and adds friction | |

**User's choice:** Self-built kod e-mail
**Notes:** Decided on the phase's own success criterion 2 (no English chrome, including third-party UI). Replacing an English third-party login with a different English third-party login would defeat the reason the phase exists.

### Allowlist storage

| Option | Description | Selected |
|--------|-------------|----------|
| Pages secret | One encrypted ADMIN_EMAILS secret; nothing personal in the public repo; adding an editor needs a secret update plus a rebuild | ✓ |
| Lista w KV, edytowalna w panelu | Self-service user management with no redeploy; costs a bootstrap path, invite flow and last-editor guard | |
| Hashed list in the repo | SHA-256 hashes committed, salt as a secret; adding an editor needs a script and a commit | |

**User's choice:** Pages secret
**Notes:** Discovered mid-discussion that `zlobekstromiec/zlobek-gminny-stromiec` is a PUBLIC repository, which turned this from a preference into a constraint.

### Session lifetime

| Option | Description | Selected |
|--------|-------------|----------|
| 30 dni, odnawiana | Sliding 30-day cookie plus a visible Wyloguj; fewest codes sent | ✓ |
| 7 dni | Middle ground; more friction, shorter exposure window | |
| Tylko na czas sesji przeglądarki | Safest on shared machines; heaviest for a one-line correction | |

**User's choice:** 30 dni, odnawiana

### Commit attribution

| Option | Description | Selected |
|--------|-------------|----------|
| Bot autor, edytor w treści | One machine identity authors; short non-personal handle in the message | ✓ |
| Bot autor, komunikat rzeczowy | Impersonal throughout; leaks nothing but loses the audit trail | |
| You decide | Delegate to Claude | |

**User's choice:** Bot autor, edytor w treści
**Notes:** Supersedes 02 D-19 (per-editor GitHub accounts), which is dead now that staff have no GitHub accounts. Full e-mail addresses must never reach a commit, same public-repo reason as above.

### Delivery mailboxes

| Option | Description | Selected |
|--------|-------------|----------|
| Gmail teraz, @ugstromiec.pl później | Allowlist starts with working addresses so the phase stays verifiable; swap is one secret update | ✓ |
| Zapytać Gminę i poczekać | Cleanest end state but makes phase completion depend on Gmina IT, with Phase 5 queued behind it | |
| Tylko jedna skrzynka na start | Smallest surface but no real staff member logs in during UAT | |

**User's choice:** Gmail teraz, @ugstromiec.pl później
**Notes:** Raised because `zlobek@ugstromiec.pl` does not exist yet. Chosen specifically to avoid repeating the FORM-01 pattern of an unverifiable requirement.

## Write path

### Commit mechanism

| Option | Description | Selected |
|--------|-------------|----------|
| Jeden commit na zapis | Git Data API (blobs, tree, commit, ref); text and image atomic in one commit and one rebuild | ✓ |
| Jedno wywołanie na plik | Contents API, simpler code, but two commits, two builds and a window where a post is live without its photo | |

**User's choice:** Jeden commit na zapis
**Notes:** Driven by aktualności entries being two files (JSON plus cover image).

### GitHub identity

| Option | Description | Selected |
|--------|-------------|----------|
| GitHub App | Org-owned, installed on one repo, short-lived tokens from a private key; no expiry, survives handover, gives the bot author identity | ✓ |
| Fine-grained PAT | Simplest possible, no JWT signing; but tied to a user account and an expiry date, so it can silently break with no developer around | |

**User's choice:** GitHub App
**Notes:** Chosen for durability after handover, which is the project's stated concern behind the dedicated accounts.

### Formatting policy (closes the Phase 3 UAT blocker)

| Option | Description | Selected |
|--------|-------------|----------|
| Panel pisze zgodnie z prettier | Tabs and trailing newline; content stays in the quality gate; pinned by a unit test | ✓ |
| Dopisać treść do .prettierignore | One line, zero code, but staff files leave the formatting gate entirely | |
| Oba | Belt and braces, but the ignore would hide future regressions in panel output | |

**User's choice:** Panel pisze zgodnie z prettier

### Concurrent edits

| Option | Description | Selected |
|--------|-------------|----------|
| Ostrzec po polsku i nie nadpisywać | SHA mismatch refuses the write and asks the editor to reload; conflict detection is free | ✓ |
| Ostatni zapis wygrywa | Simplest, but silently destroys a colleague's edit | |

**User's choice:** Ostrzec po polsku i nie nadpisywać

### Save granularity

| Option | Description | Selected |
|--------|-------------|----------|
| Jeden przycisk Zapisz na stronę | One editing session on a page is one commit and one build | ✓ |
| Zapis na sekcję | Finer control, more builds per session, more buttons for staff | |
| You decide | Delegate to Claude | |

**User's choice:** Jeden przycisk Zapisz na stronę
**Notes:** Prompted by the 500 builds per month Pages free-tier ceiling, which the user's cost constraint made relevant.

## Zdjęcia (upload i okładki)

### Where the photo is shrunk

| Option | Description | Selected |
|--------|-------------|----------|
| W przeglądarce, przed wysłaniem | Canvas resize and re-encode; near-zero Function CPU, small git history, handles iOS HEIC via the browser decoder | ✓ |
| Wysłać jak jest, z limitem rozmiaru | Highest quality source retained, simplest panel; large commits and base64 work on the tightest CPU budget | |
| Zmniejszać na serwerze | Central and consistent; no sharp on Workers and the most CPU-hostile option on the free plan | |

**User's choice:** W przeglądarce, przed wysłaniem
**Notes:** Free Workers plan allows roughly 10 ms CPU per request, and base64-encoding a multi-megabyte photo is real CPU, not I/O wait.

### Aspect ratio handling

| Option | Description | Selected |
|--------|-------------|----------|
| Panel kadruje do stałych proporcji | Automatic centred crop with a preview before saving; cards stay consistent | ✓ |
| Prosty kadrownik do przesuwania | Better results for portrait photos; costs a real interactive component with its own accessibility bar | |
| Zostawić jak jest, CSS przytnie | Zero work, original preserved; editor cannot see what will be cut | |

**User's choice:** Panel kadruje do stałych proporcji

### Filenames

| Option | Description | Selected |
|--------|-------------|----------|
| Panel generuje nazwę | ASCII slug from the entry, diacritics stripped; no collisions, no unresolvable basenames | ✓ |
| Zachować nazwę z telefonu | Keeps a link to the editor's original file; meaningless names, easy collisions, more sanitising risk | |

**User's choice:** Panel generuje nazwę
**Notes:** The basename lookup is the path-traversal defence recorded in T-03-03, so generated names must stay inside the expected directory.

### Alt text

| Option | Description | Selected |
|--------|-------------|----------|
| Wymagany, z polską podpowiedzią | No image saves without a description; accessibility becomes structural | ✓ |
| Opcjonalny, z ostrzeżeniem | Never blocks an urgent post; makes the AA baseline depend on staff discipline | |

**User's choice:** Wymagany, z polską podpowiedzią
**Notes:** Chosen because Phase 6 must certify the AA baseline in a legal document (Deklaracja dostępności).
