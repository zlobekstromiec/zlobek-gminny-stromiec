<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry -> vendored bundle | @sveltia/cms dist is committed as a static file served to admin browsers |
| admin browser (Sveltia SPA) -> GitHub API + OAuth Worker | The SPA makes cross-origin calls governed by the /admin/* CSP |
| staff input in CMS widgets -> committed content files | Widget values become on-disk JSON that the build renders |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-0204-01 | Tampering (supply chain) | vendored static/admin/sveltia-cms.js | high | mitigate | Self-host + pin @sveltia/cms 0.189.0; refresh only via the deliberate cms:sync script; no CDN hot-link; bundle committed and reviewable in git |
| T-0204-02 | Information disclosure | OAuth client secret | high | mitigate | config.yml carries only base_url (public); NO client_secret/app_secret in config.yml or the bundle (verified by grep); secret lives only on the Worker (Plan 05) |
| T-0204-03 | Tampering / stored XSS | markdown narrative widgets | medium | mitigate | Restrict markdown buttons to bold + link (D-08); no image/table/raw-HTML modes; render side uses marked.parseInline (Plan 01); site CSP script-src 'self' blocks injected inline script |
| T-0204-04 | Elevation of privilege | over-permissive /admin CSP | high | mitigate | connect-src limited to 'self' + api.github.com + the specific Worker origin; frame-src/form-action limited to github.com; no wildcard connect-src |
| T-0204-05 | Denial of service | oversized image commit breaks build/LCP | medium | mitigate | Sveltia media max_file_size (~5 MB) + webp transformation cap on upload (first layer); enhanced-img responsive output (second layer, Plan 01) |
| T-0204-06 | Tampering | broken build from a bad staff edit | medium | mitigate | Strict widgets + required fields + select for category (D-15) + boolean for placeholder; Cloudflare retains the last good deploy for rollback |

All high-severity threats (T-0204-01/02/04) have disposition mitigate, satisfying block-on-high.
</threat_model>
