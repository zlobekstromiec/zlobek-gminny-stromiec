<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| editor browser -> OAuth Worker -> GitHub | Auth code exchange happens server-side on the Worker holding the client secret |
| GitHub repo write access -> live site | A commit to main auto-deploys; repo write = publish rights |
| Worker env (secrets) -> deployment | GITHUB_CLIENT_SECRET must never leave the Worker/secret store |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-0205-01 | Information disclosure | OAuth client secret | high | mitigate | Secret set only via wrangler secret put; stored on the Worker; .dev.vars gitignored; git grep verifies absence from the repo |
| T-0205-02 | Spoofing | auth initiation from arbitrary origins | high | mitigate | ALLOWED_DOMAINS/site_domain restricts auth to the live Pages origin; callback URL fixed to <worker-url>/callback |
| T-0205-03 | Elevation of privilege | over-broad OAuth scope / Org membership | high | mitigate | Minimal OAuth App scope; per-editor Org members with write only (D-19/D-22); individually revocable |
| T-0205-04 | Tampering | direct-publish to main (no review) | medium | accept | Direct publish is the chosen model (D-20) for one or two trusted editors; strict validated schemas make broken builds unlikely; Cloudflare retains last good deploy for rollback |
| T-0205-05 | Repudiation | shared editor account hides who changed what | medium | mitigate | Per-editor GitHub accounts give a per-person git audit trail (D-19); account model confirmed with client at handover |
| T-0205-SC | Tampering (supply chain) | pinned CMS + image deps | high | mitigate | @sveltia/cms 0.189.0, @sveltejs/enhanced-img 0.11.0, marked 18.0.9 pinned in package-lock.json; marked SUS = version-recency false positive (63M dl/wk, decade-old markedjs); self-hosted CMS bundle; acknowledged in the Task 3 human-check |

All high-severity threats have disposition mitigate, satisfying block-on-high.
</threat_model>
