<objective>
Close the automated tier of the accessibility audit, fix the one real keyboard trap escape this site
has, and verify the public-information bulletin link rather than assuming it.

Purpose: D-27 defines the audit as three tiers. Tier 1 is automated and this plan finishes it, by
covering the four surfaces the contract names as uncovered. D-23 absorbs a debt from an earlier phase:
the mobile drawer's focus handler covers only the first and last members of the cycle, but the drawer
container itself is focusable, so when focus rests on the container neither branch matches, the default
is never prevented, and Shift+Tab leaks to the page beneath. That is a real WCAG 2.1 AA defect on
EVERY page, and this is the phase that certifies the baseline in a legal document, so it cannot ship
with it. D-26 keeps the bulletin link exactly where it is and asks the plan to VERIFY its properties.

Output: the drawer fix with its accepting tests, four newly covered surfaces, the bulletin link's
per-route proof, and the audit record the declaration's conformance status rests on.
</objective>
