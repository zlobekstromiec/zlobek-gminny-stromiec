Ship the accessibility widget: the site's fifth hydrated island, and the first on every route.

convention Polish visitors recognise from other public-body sites.

keyboard, and with a screen reader.

breach closed, the seven rewritten header comments D-07 requires, and the island's own acceptance
suite.

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-07-01 | Information Disclosure | `sessionStorage` preference | medium | mitigate | The keys hold two enumerated string values, no identifier, and never leave the browser, so this is a preference and not a session. It is nonetheless client-side storage on a public-body site under RODO, so plan 11 discloses it on the privacy page, and this plan's suite asserts negatively that nothing reached localStorage or a cookie. |
| T-06-07-02 | Tampering | attacker-writable `sessionStorage` values | low | mitigate | Any script that could write these keys already has full same-origin execution. The restore module nonetheless validates against an enumerated set before writing an attribute, so a hostile value cannot become an arbitrary attribute value. |
| T-06-07-03 | Elevation of Privilege | Content Security Policy | **high** | mitigate | The cheapest way to remove the pre-hydration flash is to widen `script-src` or add an inline script. Either would reopen the stored-cross-site-scripting boundary this project closed for the news body. D-12 refuses both; the plan ships the flash instead, an acceptance criterion asserts the framework config is unchanged, and the rejected alternatives are recorded in the module comment. |
| T-06-07-04 | Denial of Service | the focus trap | high | mitigate | A trap with no escape is a WCAG 2.1 AA keyboard trap on EVERY route, because this island is the first on every route. Mitigation: the corrected cycle from the gallery lightbox, the explicit Shift+Tab-from-container case, and a mutation check proving that case can go red. |
| T-06-07-05 | Denial of Service | layout shift from hydration | medium | mitigate | A third flex item appearing at hydration would register as layout shift on every route inside the phase that owns SITE-05. Mitigation: the always-rendered sized wrapper, asserted against the prerendered HTML. |
| T-06-07-06 | Repudiation | the no-JavaScript path | medium | accept | The widget renders nothing without JavaScript, which is a documented deviation from this project's standing rule (D-04). Accepted because prerendered static routes have no server, so a no-JavaScript path is structurally impossible, and the site meets AA unaided. The deviation is stated in Polish in the component header rather than left to be inferred. |
| T-06-07-SC | Tampering | npm/pip/cargo installs | high | mitigate | No install task exists in this plan. D-01 refuses the entire third-party accessibility-overlay category, which is a third-party script registry by another name, and the Content Security Policy would block one anyway. Net supply-chain movement for this phase is nil. |
