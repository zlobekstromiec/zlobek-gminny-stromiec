<objective>
Build the combined launch gate and leave it RED on purpose.

Purpose: placeholders in this repository are marked by three incompatible mechanisms, and the
existing inventory suite can only see one of them. That mismatch is exactly the content of the open
security threat T-05-09-05: a marker grep cannot see a JSON boolean, and D-19's original strict form
cannot see fourteen genuine markers living in `.svelte` markup. A gate blind to a second or third
mechanism would report clean in Phase 7 with the phone number, opening hours, address, hero headline
and next-nabór date all still unconfirmed. One command must answer "are we allowed to launch".

Output: `npm run gate:launch`, its unit suite, the reword sweep that stops the gate reading its own
documentation, and the documentation entry that stops it becoming folklore.

**This gate ships RED and that is the deliverable.** Phase 7's definition of done is that this one
command exits zero. A plan whose acceptance criteria require it green has misunderstood the phase.
</objective>
